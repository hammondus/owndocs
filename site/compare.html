Own Docs compared with Google Docs

Own Docs covers the part of Google Docs and Google Sheets that most teams use every day, on a server you run. It is not a copy of either, and this page says where it differs.

Compared on 2026-10-19. Google changes its products without notice to this page, so read the Google side as it stood on that date.

The same

  • Several people edit a document or a sheet at once, and each person sees where the others are working.
  • You comment on a text selection or a cell, reply in a thread, resolve the thread, and mention someone with @ to notify them.
  • Version history keeps every edit. You name the versions that matter and restore any earlier point. A restore is an ordinary edit, so you can undo it.
  • You share with a person at a role, or with a link.
  • A shared folder gives everyone on it access to every document inside. A document sits in one folder.
  • A sheet has tabs, formulas that reference other tabs, a fill handle, number and date formats, and charts.
  • Search finds documents by their text, and finds folders and comments.
  • Printing a document saves it as a PDF.

Different on purpose

  • Your server holds everything. Own Docs is one program and one database file on a machine you run. Accounts exist only on your instance.
  • A document is markdown text. Formatting says what something is, such as a heading, a list, or a quote, rather than how it looks. A document marked rich adds text colour, relative text sizes, highlight colours, and alignment. Fonts and page layout are absent from both kinds.
  • Nothing is public. A share link grants its role to someone who signs in on your instance. Once you close signup, new accounts come only from invite links.
  • A fifth role, manager, shares and administers a document but cannot delete it or transfer it.
  • Every cell in a sheet is locked by default. You unlock the cells that are inputs and protect the sheet, and then only the inputs accept edits. The lock stops an editor's mistake. It does not stop an editor who sets out to get around it.
  • Scripts run in a sandbox with no network and no access to your account. A script runs when you run it or, if you ask, after every edit. Google Apps Script runs with your Google identity.
  • Arithmetic can be exact. A cell can opt in to exact decimal arithmetic, and a cell that loses digits to rounding says so.
  • History compares any two points in a document, and named versions can be mirrored into a git repository, one commit per version.

Not in Own Docs

Google Docs or Google Sheets has each of these, and Own Docs does not.

Across the product

  • Slides, forms, and storage for other files. Own Docs holds documents and sheets.
  • Offline editing, and apps for phones and tablets.
  • Single sign-on and two-factor authentication.
  • Access by link without an account, and publishing to the web.
  • Assigning a comment to someone, and emoji reactions.
  • Built-in AI features, add-ons, and templates.
  • Opening or saving Word, Excel, or OpenDocument files.

Documents

  • Suggestion mode, or tracked changes.
  • Spelling and grammar checks.
  • Find and replace, and a word count.
  • Fonts, and font sizes beyond the relative sizes of a rich document.
  • Page breaks, headers, footers, page numbers, margins, and columns.
  • Equations and drawings.
  • Uploading an image. A document shows an image from a web address.
  • Downloading a document as a file. To keep a copy, print it as a PDF or mirror its versions into git.

Sheets

  • Sorting, filtering, and freezing rows or columns.
  • Data validation and dropdowns in cells.
  • Conditional formatting, merged cells, borders, and font choice.
  • Pivot tables, array formulas, and references to another file.
  • Lookup and conditional functions, such as VLOOKUP, XLOOKUP, INDEX, MATCH, SUMIF, COUNTIF, and IFERROR. The formula reference lists every function the engine has, and every Google Sheets function it lacks.
  • Charts other than column, line, and pie.
  • Opening an Excel or CSV file. Pasting from another spreadsheet works.
  • Downloading a whole workbook. Each tab downloads as a CSV file.
  • Scheduled scripts in the app. On your server, cron can run a sheet's scripts with the command-line runner.
  • Reordering tabs by dragging, and copying a tab into another sheet.
The design notes in the source repository say why each difference exists.
